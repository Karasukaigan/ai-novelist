本来计划将bin各种文件一并分发，把启动器放在里头
需求是这个：因为国内用户访问不了各种外国官网，自行下载bin下的exe，所以我希望给用户自带一个

但是发现大有问题
最大的问题就是git clone根本就无法在非空目录放东西

现在我们需要改
以后分发只分发启动器exe

启动方式是：
双击exe，进入gui
检查是否存在exe同级的qingzhu/文件夹
没有的话就说明项目还没有部署
三相按钮“检查更新”/“下载更新”/“当前已经是最新”中
下载更新需要根据qingzhu文件夹的存在与否，决定使用git clone还是拉取更新


我们现在的启动器，代码逻辑是认为自己位于ai-novelist/(或者qingzhu/) 目录下，直接拉取代码更新到qingzhu/的
但是现在需要彻底重构成平级关系

## 目录结构（分发时）

```
launcher.exe          <-- Go 启动器（Wails 桌面应用）
qingzhu/              <-- 从 git 拉取的主项目（即 ai-novelist）
    launcher/
    backend/
    frontend/
    scripts/
    data/             <-- 运行时生成的数据目录
        config/
            store.yaml
            skills.yaml
        chromadb/
        db/
        uploads/
        temp/
        skills/
        .aiignore
        .gitignore
        .userignore
```

## 关键对应关系

| 概念 | 说明 |
|------|------|
| `ai-novelist` | 本仓库的原始名称，开发时的项目名 |
| `qingzhu` | 分发时的项目目录名，启动器从 git 下载后存放的文件夹 |
| `launcher.exe` | 最终交付给用户的唯一可执行文件 |

- `qingzhu` 是 `ai-novelist` 的发布/分发名称
- 启动器通过 `config.yaml` 中的 `git.project_dir: "qingzhu"` 确定下载目标文件夹名
- 所有路径计算都基于 `exe 所在目录 / qingzhu`
